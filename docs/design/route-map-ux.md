# 정류장 찾기와 버스 선택 UX

2026-09-18 · 현재 앱 구현과 [공통 디자인 기준](asset-style-guide.md)을 기준으로 다시 작성했다. 고정 위젯 저장 시안을 대체한다. 버스 번호 검색 진입은 [버스 검색 플로우](bus-number-search-flow-proposal.md)를 구현한 흐름을 함께 제공한다.

## 사용 흐름

**버스 번호 또는 정류장 검색 → 탑승 정류장·방면 선택 → 즐겨찾기 저장 또는 대기 시작.**

버스 검색으로 진입하면 선택한 버스의 정차 정류장만 지도와 목록에 표시한다. `가까운 정류장`과 `전체 정류장`을 전환할 수 있으며, 탑승 정류장·방면 선택 즉시 해당 버스를 미리 선택한다. 같은 화면 하단에서 바로 대기·저장이 가능하고 `다른 버스 함께 선택`을 펼쳐 최대 4개로 확장한다. 별명은 선택 입력이다.

위치는 정확도 150m 이내·측정 후 120초 이내일 때만 근처 추천에 사용한다. 직선거리 1km 이내 후보를 거리순으로 정렬하며 자동 선택하지 않는다. 위치가 없거나 주변 후보가 없으면 전체 노선으로 시작한다. 전체 목록은 경유 순서이고 같은 정류장의 방향별 경유를 구분한다. 지도 마커에 여러 방향이 있으면 하단 목록에서 선택한다. 도로 경로를 제공받지 못하면 정류장 연결선을 점선으로 표시한다.

즐겨찾기가 있으면 저장한 정류장의 등록된 버스 전체를 기다릴 수 있다. 신규 사용자는 정류장 찾기에서 시작한다. 위치 권한 없이 이름·번호 검색과 지도 이동을 사용할 수 있다.

| 화면 | 먼저 읽는 정보 | 주요 행동 |
| --- | --- | --- |
| 정류장 찾기 | 검색어, 지도 위치, 정류장 이름·번호 | 지도 마커 또는 목록에서 정류장 선택 |
| 기다릴 버스 선택 | 선택한 정류장 이름·번호, 노선 번호·방면·다음 정류장 | 탈 수 있는 노선 선택, 저장 또는 대기 시작 |
| 즐겨찾기 | 저장한 정류장·방면·버스 번호 | 바로 기다리기 또는 도착정보 확인 |
| 버스 기다리기 | 등록된 전체 노선의 예상 도착·상태 | N개 버스 기다리기로 전체 대기 시작 |

## 정류장 찾기

- 검색창은 버스 번호와 정류장 이름·번호를 받는다. 버스와 정류장을 동시에 조회하고 각각의 결과·오류를 유지한다. 같은 번호의 버스는 지역·기점·종점으로 구분한다. 300ms 대기 후 검색하고 이전 요청을 취소하며 늦은 응답이 새 결과를 덮지 않게 한다.
- 검색어가 없으면 현재 지도 영역의 정류장을 조회한다. 지도 이동 후 `이 지역 다시 찾기`로 갱신한다. 검색 결과 갱신 때문에 카메라를 처음 위치로 되돌리지 않는다.
- 검색어가 있으면 버스, 정류장으로 구분한 결과 목록을 표시한다. 로딩, 조회 실패와 재시도, 결과 없음은 구분한다.
- 지도 아래 목록은 드래그 가능한 패널이다. 접힘(약 한 항목), 중간(사용 가능 영역의 40%, 기본), 펼침(검색창·탭을 제외한 목록 전체)으로 멈춘다. 목록이 펼쳐지면 스크롤하고, 목록 맨 위에서 아래로 당기면 패널을 줄인다.
- 손잡이 탭과 VoiceOver 크기 조절 동작도 제공한다. 검색을 시작하면 펼치고, 검색을 취소하면 이전 단계로 복원한다. `내 위치` 성공 시 패널을 접고 내 위치 중심 반경 150m를 보여준다.
- 검색 중에는 상단 고정 영역에 `← 돌아가기`를 표시한다. 기본 24pt의 굵은 화살표와 문구, 옅은 보조 버튼 배경, 최소 48pt 높이를 사용하며 큰 글자 설정에 맞춰 확대한다. 누르면 검색어와 키보드를 닫고 이전 패널 높이로 복원하며 지도 카메라를 유지한다. 검색창 안 지우기 버튼은 검색어만 지운다. `내 위치`는 검색 종료 후 다시 표시한다.
- 키보드가 열린 채 회전해도 시스템 검색 조작부가 잘리지 않도록 시스템 탐색·검색 영역은 최대 XXXL로 표시한다. 가로 화면의 돌아가기 문구도 최대 XXXL, 화살표는 최대 32pt로 조정한다. 세로 화면의 돌아가기 버튼과 정류장 목록은 사용자의 글자 크기를 유지하고, 돌아가기 버튼은 길게 눌러 확대해서 볼 수 있다.
- 패널을 조절할 때 지도 카메라를 새로 요청하거나 선택한 정류장을 초기화하지 않는다. 목록·지도 전환 버튼은 패널 조절로 통합한다. 가로 화면과 접근성 글자 크기에서는 목록을 우선한다. 버스 검색으로 들어간 노선 화면에서는 탐색 조작부도 함께 스크롤해 작은 화면의 목록 공간을 확보한다. 동작 줄이기 설정이면 패널 전환·저장 카드 스크롤 애니메이션을 생략한다.
- 내 위치는 사용자가 버튼을 누를 때 요청한다. 권한 거절이나 위치 조회 실패는 메시지로 알리고 나머지 탐색을 유지한다.
- 목록은 정류장 이름 전체, 정류장 번호, 선택 가능함을 나타내는 화살표 순이다. 조회된 개수는 목록의 머리말에 표시한다.
- 결과가 제한되었으면 지도를 확대하도록 안내한다. 목록 개수를 지역 전체 정류장 수로 단정하지 않는다.
- 정류장 번호는 표시 정보다. 지역별 내부 식별자를 보존하고 번호가 같다는 이유로 다른 정류장을 합치지 않는다.
- 길 건너편 정류장과 번호를 확인하도록 안내한다. 조회 데이터에 없는 방면·도보 시간은 만들어 넣지 않는다.

## 지도 표현

NAVER Maps SDK를 사용한다. 설정은 [네이버 지도 설정](../naver-maps.md), 묶음·확대·밀집 마커 배치의 정확한 정책은 [아이콘과 지도 마커](icon-and-map-refresh.md)를 따른다.

- 지도 마커는 평면 버스 심볼과 둥근 사각형으로 표현한다. 크기·체크·강조색으로 선택 상태를 함께 구분한다.
- 500m 미만에서는 조회한 정류장을 개별 표시한다. 묶음은 확대해서 선택할 수 있으며, 동일 위치 정류장도 개별 선택할 수 있게 분리한다.
- 개별 마커 중심은 정류장의 실제 좌표와 일치한다. 겹쳐도 임의로 벌리거나 연결선을 표시하지 않으며, 같은 좌표의 정류장은 목록에서 구분해 선택한다. 선택 이름은 지도 조작부와 다른 레이블을 피해서 표시한다.
- 모든 마커의 터치 영역은 최소 44pt이며, 목록으로도 같은 정류장을 선택할 수 있다.
- 지도 타일을 불러오지 못하면 목록 사용 안내를 표시한다. SDK 로고와 저작권 표시는 가리지 않는다.
- VoiceOver는 정류장 이름·번호·선택 상태를 읽는다. 지도 데이터에서 알 수 없는 버스별 방면은 다음 화면에서 확인한다.

## 버스 선택과 저장

- 상단에 정류장 이름·번호를 한 묶음으로 표시하고 길 건너편 정류장, 버스별 방면·다음 정류장 확인 안내를 이어서 표시한다.
- 선택 행은 노선 번호 → 방면 → 다음 정류장 또는 선택 불가 이유 순으로 읽힌다. 오른쪽 원형 체크와 옅은 배경으로 선택을 구분한다.
- 최대 4개 노선을 선택한다. 같은 노선의 다른 경유 방향을 선택하면 그 노선의 기존 선택을 바꾼다. 선택 불가 항목에는 데이터가 제공한 이유를 표시한다.
- `탈 수 있는 버스` 제목 옆에 작은 새로고침 아이콘을 둔다. 터치 영역은 44pt이며 조회 중에는 중복 실행을 막는다. 일부 노선 조회 실패 안내와 별도의 `다시 시도` 행은 표시하지 않는다. 새로고침 중에도 기존 목록과 선택을 유지한다.
- 선택한 노선의 도착정보는 그 노선 행에서 번호·방면·체크와 함께 표시한다. 선택한 버스를 별도 목록으로 반복하지 않는다. 별명은 선택 입력이며, 예상 도착이 없어도 유효한 탑승 조합은 저장할 수 있다.
- 노선 번호·방면·도착정보는 큰 글자에서도 줄바꿈한다. 같은 행을 다시 눌러 선택을 해제한다.
- 하단 주요 버튼은 진입 목적에 따라 구분한다. 즐겨찾기에서 추가하면 `즐겨찾기에 추가`, 지도에서 탐색하면 `N개 버스 기다리기`, 기존 항목 수정이면 `변경 저장`이다. 지도 탐색에서도 하단 대기 버튼 위에 보조 동작으로 즐겨찾기 저장을 제공한다.
- 선택 없음·검증 중에는 실행하지 못하며 검증 중임을 표시한다. 저장 성공 시 선택 화면을 닫고 즐겨찾기 탭의 실제 저장된 카드를 보여준다. 실패 시 이동하지 않고 선택과 오류를 유지한다.
- 저장·대기 시작 전에 서버에서 선택 관계를 검증한다. 실패 시 오류와 선택 상태를 유지한다.
- 기존 즐겨찾기를 변경할 때 최종 저장 전까지 기존 데이터를 유지한다. 저장하지 않은 변경을 닫을 때는 폐기 여부를 확인한다.
- 즐겨찾기 카드는 버스 번호만 표시하며 시간·`도착정보 · 버스 선택` 문구·카드의 점 3개 메뉴를 생략한다. 카드 본문으로 상세에 진입하고 왼쪽 밀기로 삭제한다.
- 즐겨찾기 상세는 명시적인 `뒤로` 버튼을 제공하며, 도착 예정 시간까지 `분:초` 카운트다운을 매초 갱신한다.
- 즐겨찾기 상세는 `기다릴 버스 · N개` 아래 등록된 전체 노선을 표시하며 행 선택·해제는 제공하지 않는다. `N개 버스 기다리기`를 누르면 전체 노선의 대기를 시작한다.
- 상세 하단 카드는 `현재 대기 보기`(대기 중일 때만), `즐겨찾기에 저장됨`, `정류장·버스 변경`으로 구성한다. 가장 먼저 도착하는 버스 안내, 오늘의 선택 안내, 마지막 확인 시각은 표시하지 않는다. 오류·재시도는 별도 영역에서 제공한다.

## 색상·서체·표면

공통 토큰은 [디자인 기준](asset-style-guide.md)에서 관리한다. 밝은 회색 바탕, 흰색 표면, 짙은 본문과 읽을 수 있는 회색 설명, 차분한 블루 행동 색상을 사용한다.

시스템 탐색·시트·서체를 유지하고 장식용 3D 에셋은 사용하지 않는다. 하단 행동 영역은 불투명한 표면과 얇은 구분선으로 구성하며, 스크롤의 마지막 항목과 안전 영역을 가리지 않는다.

## 상태와 정보의 정확성

| 상황 | 표현과 회복 방법 |
| --- | --- |
| 검색 중 | 진행 표시. 이전 요청의 늦은 응답을 버림 |
| 검색 결과 없음 | 빈 상태와 다른 이름·번호 또는 지도 위치 안내 |
| 정류장·경유 버스 조회 실패 | 오류와 다시 시도 |
| 일부 노선 정보만 조회됨 | 서버 경고를 표시하고 확인 가능한 항목을 구분 |
| 도착정보 없음 | 도착정보 없음으로 표시. 임의의 예상 시간은 만들지 않음 |
| 오래된 도착정보 | 남은 카운트다운 유지, 예정 시각 경과 시 ‘다시 연결 중’ |
| 선택 불가 경유 정보 | 서버의 선택 불가 사유를 표시 |
| 저장 실패 | 선택과 기존 즐겨찾기를 유지하고 오류 표시 |

## 검증과 참고 자료

`make test-route-ui`는 합성 API와 격리된 저장소로 지도·선택·저장·재실행·큰 글자·가로 화면을 확인한다. 정류장·노선 데이터 계약은 [API 설계](route-map-api.md)를 따른다.

2026-09-18 검증: iPhone 17 Pro·iPhone SE 3세대(iOS 26.5)에서 패널 손잡이 드래그·탭, 펼친 목록 스크롤과 맨 위에서 축소, 검색 취소 시 높이 복원, 지도 이동·축척 유지, 내 위치, 큰 글씨·가로 화면을 확인했다. 저장·삭제·패널을 포함한 UI 시나리오 17개는 변경된 동작에 맞춘 재검증까지 통과했다.

`route-map-prototype.html`과 `route-map-preview.png`는 2026-09-17의 과거 버스 번호 우선 흐름을 보존한 자료다. 현재 화면이나 색상 기준으로 사용하지 않는다.

### 검색 돌아가기 개선 검증

iPhone SE 3세대(375pt)와 iPhone 17 Pro 시뮬레이터에서 검색 종료·키보드 닫기·이전 패널 높이와 지도 축척 복원을 확인했다. SE의 최대 접근성 글자·다크 모드·가로 화면에서는 돌아가기 버튼이 검색창과 키보드 사이에 전부 들어오는지 검사한다. 버튼 전경/배경 대비는 밝은 화면 5.12:1, 어두운 화면 7.31:1이다.
