# 즐겨찾기 화면 디자인 · 2026-09-18

[공통 디자인 기준](asset-style-guide.md)의 색상·서체·간격을 따른다.

사용자는 정류장에서 집에 갈 수 있는 버스 중 하나를 기다린다. 즐겨찾기의 목적은 저장한 정류장과 버스를 빠르게 확인하고 오늘의 대기를 시작하는 것이다.

- 저장한 항목이 있으면 제목 아래 `저장한 정류장 N개`를 표시한다.
- 빈 상태는 작은 북마크 심볼, `저장한 정류장이 없습니다`, 짧은 저장 안내와 정류장 추가 버튼으로 구성한다.
- 밝은 회색 화면 위에 흰색 카드를 배치한다. 직접 제작한 카드의 모서리는 16pt, 내부 여백은 20pt이며 얇은 구분선만 사용한다.
- 카드는 별명(있을 때), 정류장 이름, 정류장 번호·방향, 버스 번호 배지 순으로 읽힌다. 노선 배지는 중립적인 밝은 회색 바탕과 짙은 글자를 사용하고, 큰 글자에서도 줄바꿈한다.
- 카드 본문은 등록된 전체 버스의 도착정보 상세 화면을 연다. `바로 기다리기`는 저장한 모든 버스로 대기 시작을 자동 시도한다. 시작 실패는 상세 화면에 원인과 재시도를 제공한다. 기존 대기가 있거나 처리 중이면 중복 시작을 막는다.
- 카드를 왼쪽으로 밀면 빨간 휴지통과 `삭제`가 나타난다. 끝까지 밀어도 삭제하지 않으며 버튼을 눌러야 삭제한다. 카드의 `⋯` 메뉴는 표시하지 않는다.
- 삭제 성공 후 `즐겨찾기를 삭제했어요 · 실행 취소`를 8초 동안 제공한다. VoiceOver 사용 중에는 시간 제한을 두지 않는다. 실행 취소는 삭제한 항목을 원래 순서에 복원하고, 그 사이 추가·수정한 항목을 덮어쓰지 않는다. 연속 삭제 시 가장 최근 삭제만 복구한다. 현재 대기는 유지한다.
- 즐겨찾기 저장 성공 시 선택·편집 화면을 닫고 즐겨찾기 탭으로 돌아온다. 저장한 카드로 스크롤하고 잠시 테두리를 강조하며 저장 완료 메시지를 표시한다. 중복 저장으로 기존 항목을 갱신한 경우에도 실제 저장된 카드로 이동한다.
- 목록 아래 `+ 자주 타는 정류장 추가`를 배치한다. 빈 화면에서는 주요 버튼, 저장한 항목이 있으면 보조 버튼으로 표시한다. 개인정보처리방침은 상단 `더보기` 메뉴에 둔다.
- 카드의 배지는 버스 번호만 표시하며, 도착 시간과 `도착정보 · 버스 선택` 안내는 표시하지 않는다. 화면에 보이는 카드의 도착정보는 캐시를 위해 갱신하고 상세 화면에서 표시한다.

## 대기 상세 화면

정류장 이름·번호 다음에 `기다릴 버스 · N개`와 등록된 전체 노선의 예상 도착·상태를 배치한다. 상단의 `뒤로` 버튼으로 이전 화면에 돌아간다. 남은 시간은 `분:초` 형식으로 매초 줄어들며, 예정 시각이 지나면 기존 연결 상태 문구를 표시한다. 노선과 시간이 가로로 들어가지 않으면 세로로 배치한다. 체크와 선택·해제 동작은 제공하지 않는다. 하단의 `N개 버스 기다리기`를 누르면 전체 노선 대기를 시작하며, 상세 진입만으로 시작하지 않는다. 가장 먼저 도착 안내, 오늘의 선택 안내, 마지막 확인 시각은 표시하지 않는다. 하단 카드는 `현재 대기 보기`(대기 중에만), `즐겨찾기에 저장됨`, `정류장·버스 변경`으로 구성한다. 오류와 재시도는 별도 영역에 표시하고 이름 변경·삭제 메뉴는 유지한다.

## 유지하는 데이터와 위젯 정책

홈 화면·잠금 화면 고정 위젯, 위젯에 표시하는 조합 설정, 해당 타임라인·캐시·이전 설정 화면을 제거한다. 실시간 현황, Dynamic Island, 진행 중인 대기 복원과 APNs는 유지한다. ActivityKit을 위해 기존 WidgetKit 확장 타깃·번들 ID를 유지한다.

기존 위젯 설정만 있는 사용자는 최초 실행 시 즐겨찾기로 가져온다. 이미 저장된 즐겨찾기가 있으면 이를 우선한다. 디코딩 또는 저장 실패 시 이전 설정을 지우지 않으며, 마지막 즐겨찾기를 지워도 과거 설정을 다시 가져오지 않는다.

새 저장 데이터는 경유 정보에 포함된 버스 이름을 바로 표시한다. 버스 이름이 없는 예전 데이터는 정류장 API에서 이름을 보강해 기기에 저장한다. 조회 실패 시 즐겨찾기와 선택은 유지하고 다시 확인할 수 있다. 늦게 도착한 응답이 삭제한 즐겨찾기를 복원하거나 사용자의 정류장·버스 편집을 덮어쓰지 않는다.

검증(2026-09-18): 단위 테스트 53개 통과. iPhone 17 Pro와 iPhone SE 3세대(iOS 26.5)에서 저장 후 자동 이동, 수정 후 복귀, 스와이프·메뉴 삭제, 실행 취소·재실행 후 보존, 바로 대기 시작 시도와 오류 안내, 큰 글자·다크 모드·가로 화면을 확인했다. 실제 APNs 전달은 배포 환경과 기기에서 별도로 확인한다.
