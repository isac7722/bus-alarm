# 아이콘과 지도 마커 개선

2026-09-18 확정한 [차분한 정보형 디자인 기준](asset-style-guide.md)을 따른다. 아래 지도 동작 정책은 유지한다.

- 즐겨찾기는 북마크, 정류장 찾기 탭은 버스 심볼을 사용한다. 탭 이름은 유지한다.
- 지도 마커는 넓은 지역에서도 버스 모양이 보이는 24pt 마커, 동네에서 28pt 버스, 상세에서 32pt 버스로 표시한다. 선택한 정류장은 36pt로 강조한다. 터치 영역은 항상 44pt다.
- 줌 단계는 14.5와 16.5를 기준으로 양쪽 0.2의 여유를 둬 경계에서 반복 전환되지 않게 한다. 크기 변화는 180ms이며 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 200m를 포함해 지도 축척이 500m 미만이면 조회된 정류장을 모두 개별 표시한다. 500m부터 화면상 28pt 이내에 있는 정류장만 32pt 버스와 숫자 배지로 묶고, 1km 이상에서는 36pt를 사용한다. 긴 도로를 따라 연쇄적으로 묶이지 않도록 묶음 전체의 가로·세로 범위를 거리 기준의 두 배로 제한한다. 선택한 정류장은 항상 묶음에서 제외한다.
- 축척은 NAVER SDK의 공개 `NMFScaleView.scaleBarWidthConstraint`와 지도 좌표 변환으로 읽는다. 막대 너비에 해당하는 실제 거리를 1·2·5 계열로 반올림하므로 위도나 화면 배율이 달라져도 특정 줌 번호에 의존하지 않는다. 축척이 아직 준비되지 않았으면 개별 표시한다. VoiceOver에도 현재 축척을 제공한다.
- 묶음을 누르면 구성 정류장의 화면 범위와 간격을 이용해 확대량을 계산한다. 지도 조작부와 가장자리 여백을 제외한 영역에 정류장들이 남도록 제한하고, 기본적으로 100m 수준까지 확대한다. 동일 좌표도 확대 후 개별 아이콘으로 분리한다. 이동은 280ms이며 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 겹치는 개별 아이콘은 지도 안에서 가까운 빈 자리로 벌리고 실제 위치까지 가는 얇은 연결선과 원점을 표시한다. 선택한 정류장의 위치를 우선 보존하고, 표시 순서와 배치를 결정적으로 유지한다. 44pt 터치 영역이 일부 겹치면 터치 지점에 가장 가까운 정류장을 선택한다. 밀집도가 화면의 수용량을 초과하면 기존 정류장 목록에서도 각각 선택할 수 있다. 숫자는 현재 조회된 데이터의 정류장 수이며 지역 전체 정류장 수나 버스 대수가 아니다.
- 묶음과 분리 배치는 지도 이동이 멈춘 뒤 갱신하고 이동 중에는 기존 배치를 유지한다. 상세 단계의 정류장 이름은 다른 마커·이름·지도 조작부를 가리지 않을 때 표시한다. 선택한 정류장 이름은 모든 축척에서 우선 배치하며 아래가 막혔으면 위쪽도 확인한다. VoiceOver는 모든 마커의 이름과 선택 상태를 읽는다. 방면 정보는 기존 정류장 선택 화면에서 확인하며, 지도 데이터에 없는 방면을 추측하지 않는다.
- 앱 아이콘은 밝은 회색 배경과 차분한 블루의 평면 버스 심볼로 교체한다. 앱 내부의 버스 표시는 SF Symbols의 평면 버스 계열로 맞춘다.
- 지도 마커는 둥근 사각형 표면에 버스 심볼을 표시한다. 일반 상태는 밝은 표면과 블루 테두리, 선택 상태는 강조색 채움과 체크 배지로 구분한다. 묶음 숫자, 선택 상태, 44pt 터치 영역은 유지한다.
- 지도 확대·축소, 이름 레이블, 경로 강조는 공통 팔레트를 사용한다. 지도 타일·로고·저작권 표시는 SDK 기본 정책을 유지한다.

## 앱 아이콘 제작 기록

현재 아이콘 파일, 생성 도구와 프롬프트는 [앱 아이콘 문서](../app-icon.md)에서 관리한다. 이전 유리·무광 입체 아이콘은 현재 디자인 기준으로 사용하지 않는다.

## 검증

`make test-ios`에는 줌 경계 안정성, 200m·500m 묶음 정책, 선택 정류장 제외, 밀집 정류장의 누락 방지·묶음 범위 제한, 동일 좌표 분리 배치, 확대 후 화면 범위와 44pt 터치 영역 검증이 포함된다. `make test-route-ui`는 합성 API로 실제 SDK 축척에 따른 개별·묶음 전환, 묶음 확대, 동일 좌표 개별 선택과 선택 상태 유지, 기존 즐겨찾기·다중 버스 선택 흐름을 확인한다.

색상 개편 전 지도 동작 검증 기록 (2026-09-18): iPhone 17 Pro에서 단위 테스트 44개와 UI 테스트 9개 통과. iPhone SE 3세대(375pt)에서 단위 테스트 44개와 지도 UI 테스트 4개 통과. 연결선 레이어와 이름 여백 보정 후 관련 UI 테스트 2개를 다시 실행해 통과했고, 200m 개별 표시·500m 묶음·선택 이름·연결선을 캡처로 확인했다.
