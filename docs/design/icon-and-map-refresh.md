# 아이콘과 지도 마커 개선

2026-09-18 확정한 [차분한 정보형 디자인 기준](asset-style-guide.md)을 따른다. 아래 지도 동작 정책은 유지한다.

- 즐겨찾기는 북마크, 정류장 찾기 탭은 버스 심볼을 사용한다. 탭 이름은 유지한다.
- 지도 마커는 넓은 지역에서도 버스 모양이 보이는 24pt 마커, 동네에서 28pt 버스, 상세에서 32pt 버스로 표시한다. 선택한 정류장은 36pt로 강조한다. 터치 영역은 항상 44pt다.
- 줌 단계는 14.5와 16.5를 기준으로 양쪽 0.2의 여유를 둬 경계에서 반복 전환되지 않게 한다. 크기 변화는 180ms이며 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 200m를 포함해 지도 축척이 500m 미만이면 조회된 정류장을 모두 개별 표시한다. 500m부터 화면상 28pt 이내에 있는 정류장만 32pt 버스와 숫자 배지로 묶고, 1km 이상에서는 36pt를 사용한다. 긴 도로를 따라 연쇄적으로 묶이지 않도록 묶음 전체의 가로·세로 범위를 거리 기준의 두 배로 제한한다. 선택한 정류장은 항상 묶음에서 제외한다.
- 축척은 NAVER SDK의 공개 `NMFScaleView.scaleBarWidthConstraint`와 지도 좌표 변환으로 읽는다. 막대 너비에 해당하는 실제 거리를 1·2·5 계열로 반올림하므로 위도나 화면 배율이 달라져도 특정 줌 번호에 의존하지 않는다. 축척이 아직 준비되지 않았으면 개별 표시한다. VoiceOver에도 현재 축척을 제공한다.
- 묶음을 누르면 구성 정류장의 화면 범위와 간격을 이용해 확대량을 계산한다. 지도 조작부와 가장자리 여백을 제외한 영역에 정류장들이 남도록 제한하고, 기본적으로 100m 수준까지 확대한다. 동일 좌표는 확대 후에도 같은 위치에 겹쳐 표시하며 목록에서 구분해 선택한다. 이동은 280ms이며 동작 줄이기 설정에서는 애니메이션을 생략한다.
- 개별 정류장 아이콘의 중심은 위도·경도를 지도에 투영한 좌표와 일치한다. 아이콘 사이에 최소 표시 간격을 강제하지 않고, 겹침 방지 오프셋·연결선·별도 원점을 사용하지 않는다. 선택 강조는 중심을 옮기지 않고 색상·크기·체크 표시로 표현한다. 44pt 터치 영역이 겹치면 터치 지점에 가장 가까운 정류장을 선택하며, 거리가 같으면 현재 선택한 정류장을 우선한다. 같은 좌표의 정류장은 아래 목록에서 각각 선택할 수 있다. 숫자 배지가 있는 묶음은 개별 정류장이 아닌 여러 정류장의 대표 위치이며, 구성 좌표의 화면상 중심에 표시한다.
- 묶음 구성은 지도 이동이 멈춘 뒤 갱신하며, 이동 중에도 아이콘 위치는 실제 좌표를 따라간다. 상세 단계의 정류장 이름은 다른 마커·이름·지도 조작부를 가리지 않을 때 표시한다. 선택한 정류장 이름은 모든 축척에서 우선 배치하며 아래가 막혔으면 위쪽도 확인한다. VoiceOver는 모든 마커의 이름과 선택 상태를 읽는다. 방면 정보는 기존 정류장 선택 화면에서 확인하며, 지도 데이터에 없는 방면을 추측하지 않는다.
- 앱 아이콘은 밝은 회색 배경과 차분한 블루의 평면 버스 심볼로 교체한다. 앱 내부의 버스 표시는 SF Symbols의 평면 버스 계열로 맞춘다.
- 지도 마커는 둥근 사각형 표면에 버스 심볼을 표시한다. 일반 상태는 밝은 표면과 블루 테두리, 선택 상태는 강조색 채움과 체크 배지로 구분한다. 묶음 숫자, 선택 상태, 44pt 터치 영역은 유지한다.
- 지도 확대·축소, 이름 레이블, 경로 강조는 공통 팔레트를 사용한다. 지도 타일·로고·저작권 표시는 SDK 기본 정책을 유지한다.
- 선택한 버스 노선에서 가장 가까운 정류장은 크기·채움·이름으로 강조하고 묶음에서 제외한다. 승차 선택의 체크 배지와 VoiceOver 선택 상태는 붙이지 않는다. 내 위치 점은 가까운 정류장 아이콘에 가려지지 않도록 앞에 표시하며 좌표는 옮기지 않는다.

## 내 위치와 지도 재검색

- `내 위치`를 누르면 새 위치를 확인하고, 해당 좌표를 중심으로 반경 150m가 들어오는 영역(가로·세로 300m)을 화면에 맞춘다. 지도의 가로세로 비율에 따라 더 긴 방향에는 추가 영역이 보인다. 축척 막대를 150m로 고정한다는 의미는 아니다.
- 버스 경로 화면에서는 내 위치와 해당 노선의 가장 가까운 정류장을 함께 맞춘다. 주변 5km 이내 정류장은 목록에 거리순으로 제공한다. 가까운 정류장이 없을 때에도 내 위치를 유지하며, 전체 노선은 `전체 경로`로 확인한다.
- 같은 좌표에서 다시 눌러도 현재 위치로 돌아온다. 위치 확인 중에는 작은 진행 표시와 비활성 상태를 사용한다. 위치 권한을 거절하거나 조회에 실패해도 지도·목록 탐색은 계속 사용할 수 있다.
- 일시적인 위치 조회 실패는 1초 간격으로 최대 두 번 재시도한다. 조회가 이미 성공한 뒤 도착하는 실패 응답으로 위치 점을 지우지 않는다. 접근성 글자 크기의 세로 화면에서는 지도 전환과 내 위치 버튼을 세로로 배치한다.
- 위치는 요청 시 확인하며, 마지막 확인한 좌표를 작은 블루 점으로 표시한다. 정류장 겹침 분리나 선택에 따라 위치 점을 옮기지 않는다. VoiceOver에는 `내 위치, 마지막 확인한 위치`로 읽힌다.
- 16pt 중심 점은 항상 보인다. 32pt 바깥 원만 불투명도 0.12~0.26 사이에서 2.8초 주기로 천천히 변화한다. 크기 확대나 번쩍임은 사용하지 않는다. 동작 줄이기·비활성 화면·지도 밖에서는 반복 효과를 멈춘다.
- 위치 정확도가 150m보다 낮으면 위치가 부정확할 수 있다는 안내를 표시한다. 반경 150m는 지도 표시 범위이며 GPS 정확도를 보장하는 값이 아니다.
- `이 지역 다시 찾기`는 흰색/어두운 표면과 블루 글자의 작은 캡슐 버튼으로 표시한다. subheadline semibold, 좌우 12pt·상하 8pt 여백, 시각적 최소 높이 36pt를 사용한다. 터치 영역은 최소 44pt이며 큰 글자는 시스템 설정에 따라 커진다.

## 앱 아이콘 제작 기록

현재 아이콘 파일, 생성 도구와 프롬프트는 [앱 아이콘 문서](../app-icon.md)에서 관리한다. 이전 유리·무광 입체 아이콘은 현재 디자인 기준으로 사용하지 않는다.

## 검증

`make test-ios`에는 줌 경계 안정성, 200m·500m 묶음 정책, 선택 정류장 제외, 밀집 정류장의 누락 방지·묶음 범위 제한, 동일 좌표의 중심 일치, 확대 후 화면 범위와 44pt 터치 영역 검증이 포함된다. `make test-route-ui`는 합성 API로 실제 SDK 축척에 따른 개별·묶음 전환, 묶음 확대, 동일 좌표의 아이콘 겹침·목록 선택과 선택 상태 유지, 기존 즐겨찾기·다중 버스 선택 흐름을 확인한다.

색상 개편 전 지도 동작 검증 기록 (2026-09-18): iPhone 17 Pro에서 단위 테스트 44개와 UI 테스트 9개 통과. iPhone SE 3세대(375pt)에서 단위 테스트 44개와 지도 UI 테스트 4개 통과. 연결선 레이어와 이름 여백 보정 후 관련 UI 테스트 2개를 다시 실행해 통과했고, 200m 개별 표시·500m 묶음·선택 이름·연결선을 캡처로 확인했다.

선택 시 위치 이동 수정 (2026-09-18): 같은 좌표의 두 정류장 중 두 번째를 선택하면 첫 번째 아이콘이 44pt 이동하는 문제를 UI 테스트로 재현했다. 겹침 분리 순서에서 선택 우선순위를 제거한 뒤 양쪽 정류장을 번갈아 선택해도 두 아이콘의 중심 좌표가 1pt 허용 오차 안에서 유지됨을 확인했다. 지도 관련 UI 4개(반복 선택, 묶음 확대, 동일 좌표 분리, 이동·검색 후 카메라 유지)와 마커 단위 테스트 9개가 통과했다. 당시에는 연결선·원점과 겹침 분리를 유지했으며, 이후 좌표 일치 요구사항에 따라 제거했다.

내 위치·재검색 개선 (2026-09-18): 반경 150m 계산, 반복 위치 요청, 늦은 실패 응답 무시, 위치 애니메이션 중지 조건을 포함한 단위 테스트 14개 통과. iPhone 17 Pro에서 밝은/어두운 화면의 위치 확인·지도 이동 후 재이동·재검색 UI 2개 통과. 375pt iPhone SE에서는 같은 UI 2개와 최대 글자·가로 화면의 조작부 확인 1개 통과. 위치는 XCTest의 모의 좌표로 검증했으며 실제 기기의 GPS 수신 품질을 검증한 결과는 아니다. 동작 줄이기·비활성 상태는 애니메이션 중지 조건과 단위 테스트로 확인했다.

실제 시뮬레이터 화면: [밝은 화면](previews/calm/my-location-light.png), [어두운 화면](previews/calm/my-location-dark.png). 캡처의 정류장과 위치는 테스트 데이터다. 검사 결과는 `/tmp/bus-location-refresh/`의 `unit-complete.xcresult`, `final-ui.xcresult`, `small-final.xcresult`에 남겼다.

좌표 일치 적용 (2026-09-18): 아이콘을 빈 자리로 옮기는 계산과 연결선·원점을 제거했다. 같은 좌표의 정류장 두 개가 동일한 화면 중심에 표시되고, 목록에서 번갈아 선택해도 그 중심이 유지되는 것을 확인했다. 동일 좌표의 선택된 마커를 다시 누르면 선택된 정류장을 유지한다. 관련 단위 테스트 14개, 묶음 확대·동일 좌표 표시·목록 선택·지도 이동 후 카메라 유지 UI 테스트 4개 통과. 결과는 `/tmp/bus-exact-coordinates/unit.xcresult`와 `ui.xcresult`에 남겼다.
